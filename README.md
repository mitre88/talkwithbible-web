# Talk with the Bible

Product website for the iOS app **Talk with the Bible** — a private, on-device King James companion.

## Pages

- `/` landing
- `/privacy` Privacy Policy
- `/support` Support
- `/terms` Terms of Use

English is the default. Spanish (`/es`) and French (`/fr`) are first-class.

## Stack

Next.js 15, TypeScript, Tailwind CSS 4, next-intl, next-themes, Framer Motion, pnpm.

## Local

```bash
pnpm install
pnpm dev
```

## Privacy

The app does not collect personal data. Chats stay on the iPhone. There is no account, no analytics SDK, and no cloud of ours. Apple Intelligence runs on-device. Reminders are local notifications.
